# Matcho

Matcho is a modern multi-sport tournament management platform designed to simplify the organization of sports events. It enables organizers to create tournaments, manage teams, schedule matches, update live scores, and provide real-time updates to spectators through a single platform.

## Key Features
- 🏆 Multi-sport tournament management
- 📅 Match scheduling
- ⚡ Real-time live scoring
- 👥 Role-based access (Admin, Scorer, Audience)
- 📊 Live dashboards and standings
- 📱 Responsive web application
- 🔄 Real-time updates using WebSockets

## Tech Stack
- React + TypeScript + Tailwind CSS
- Node.js + Express
- PostgreSQL
- Socket.IO
- JWT Authentication
